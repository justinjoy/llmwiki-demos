# 원장 장애 시 결제 대사 작업 중지·재개

문서 번호: OPS-04 v1  
담당: 결제정산팀·SRE  
상태: 승인 완료  
최종 수정: 2026-08-21  
적용 대상: 운영 환경 · 대상 가맹점의 결제 대사 작업

## 1. 작업 전 확인

원장 저장 타임아웃이 5분 이상 이어지고 PG 승인 내역과 원장 기록의 불일치가 확인되면 대사 작업의 일시 중지를 검토한다. 요청 로그와 큐 현황을 확인해 대상 가맹점 ID(merchant_id) 목록을 작성한다. 고객의 재결제 여부도 함께 확인한다.

결제정산팀 당직자와 장애 대응 책임자의 승인을 받은 뒤 작업한다. 장애 대응 채널에 대상 가맹점, 중지 사유, 승인자, 작업 시작 시각을 남긴다.

## 2. 중지 및 재개

승인받은 가맹점의 결제 대사 큐 소비를 일시 중지한다. PG 승인 API와 다른 가맹점의 대사 작업은 계속 운영한다.

원장 상태가 안정되면 다음 순서로 재개한다.

1. 보류 중인 결제의 PG 승인 내역과 원장 기록을 결제 ID별로 비교한다.
2. 승인 결과가 확인되지 않은 건은 보류 목록에 남긴다.
3. 승인 결과가 확인된 건부터 기존 결제 ID(payment_id)로 대사를 재개한다. 신규 승인 요청을 만들지 않는다.
4. 재처리 후 중복 승인, 중복 원장 기록, 남은 대사 건수를 확인한다.

중지·재개 작업은 운영 콘솔에서 수행한다. 작업자는 처리 결과와 남은 보류 건을 장애 대응 채널에 공유한다.

## 3. 작업 종료

신규 주문이 정상 처리되는지 확인한 뒤 고객센터에 상황을 공유한다. 보류된 결제 건의 대사까지 끝나면 작업을 종료한다.

장애 보고서에는 장애 시작, 신규 주문 정상화, 대사 완료 시각을 각각 기록한다. 아직 처리하지 못한 건이 있으면 결제 ID, 보류 사유, 담당자를 인계한다. 고객 공지에 넣을 복구 예상 시각은 장애 대응 책임자가 확인한다.
