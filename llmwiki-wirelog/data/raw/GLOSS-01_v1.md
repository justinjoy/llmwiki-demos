# 결제 시스템 용어 및 서비스명

문서 번호: GLOSS-01 v1  
담당: 결제정산팀  
상태: 승인 완료  
최종 수정: 2026-08-13  
적용 대상: 결제·정산 시스템 공통

## 1. 서비스명

결제 서비스의 공식 ID는 pay이며, 기존 문서의 payment도 같은 서비스를 가리킨다. 배포 리소스 이름은 payment-api다.

| 이름 | 용도 | 비고 |
| --- | --- | --- |
| shop | 쇼핑몰 화면용 서버(BFF) | 주문 접수 및 처리 상태 조회 |
| order | 주문 서비스 | 주문 생성·상태 관리 |
| pay / payment | 결제 서비스 | 카드 승인 요청·결제 내역 대사 |
| ledger | 원장 서비스 | 결제 내역 저장·조회 API |
| ledger-db | 원장 데이터베이스 | ledger가 사용하는 DB |
| ledger-batch | 원장 배치 작업 | 결산용 집계 등 정기 작업 |
| notify | 알림 워커 | 주문 완료 알림 발송 |

## 2. 식별자와 상태값

| 항목 | 의미 |
| --- | --- |
| order_id | 주문 번호 |
| payment_id | 결제 시도를 구분하는 ID. 기존 결제 건을 조회·재처리할 때 그대로 사용 |
| merchant_id | PG 가맹점 ID |
| entry_type | 원장 전표 유형 |
| PAYMENT_PENDING | 주문 상태: 결제 결과 확인 중 |
| CONFIRMED | 주문 상태: 주문 확정 |
| LEDGER_PENDING | 결제 처리 상태: PG 승인 후 원장 반영 대기 |

대사는 PG 승인 내역과 내부 원장 기록을 대조해 누락이나 불일치를 확인하는 작업이다. ‘승인’이라고만 적으면 카드 승인과 업무 승인을 혼동할 수 있으므로 장애 기록에는 ‘PG 승인’, ‘변경 승인’, ‘조치 승인’으로 구분해 쓴다.
