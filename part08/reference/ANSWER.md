# 8교시 정답 해설

한빛MRO 합성 문서 기반 예시입니다. 실제 검토자·일자는 수강생이 기록합니다. 문구가 달라도 근거·범위·상태가 같으면 됩니다.

## PPT 11: 실습 A 확인: 주장별 검토

숫자·권한·상태의 의미를 근거와 대조합니다.

| 주장 | 유형 | 검토 기준 |
| --- | --- | --- |
| pay가 ledger 쓰기 API 호출 | 원문 사실 | ARCH-01 v1 §2 |
| notify가 점검 후보 | 규칙 결론 | S1b / F04·F02·F03 |
| 모든 주문이 25분 중단 | 과잉 해석 | 186/4,900건 지연과 구분 |
| 전체 결제 재시도 즉시 중지 | 근거 부족 | 대사 큐 범위·조건·승인 필요 |
| 미래 복구 시간 미확인 | 현재 정보 공백 | 과거 관측과 구분 |

## PPT 13: 실습 B 확인: 분석 페이지

결론의 기준과 적용 범위를 페이지에 남깁니다.

```text
# ledger 지연 영향 검토
기준: S1b / 규칙: candidate-v1 / 상태: 검토 대기
후보: shop, order, pay, notify
notify 경로: F04 → F02 → F03 / 영향: 알림 지연 점검
과거 관측: 신규 영향 25분, 대사 완료 42분 [INC-03 v1 §3]
조치: OPS-04의 조건·영향 범위·실행 승인 확인 필요
미확인: 현재 지표, 불일치 목록, 승인, 향후 복구 시각
검토자·일자: 실제 원문·경로·링크 확인 후 기록
```

## PPT 16: 종합 확인 문제 해설

경로·업무 영향·현재 적용 조건을 따로 설명합니다.

### 질문 1의 답

F04·F02·F03과 S1b를 추적합니다.
RUN-02의 발송 보류·격리를 읽습니다.
결제 실패와 같은 영향으로 단정하지 않습니다.

### 질문 2의 답

25분은 과거 신규 요청 영향입니다.
OPS-04는 절차 자체의 승인입니다.
현재 조건과 건별 실행 승인은 추가 확인합니다.
