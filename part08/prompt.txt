8교시 실습 A: 문서에서 근거를 찾아 질문에 답하라.

질문: ledger 지연 시 점검 대상과 조치 판단 근거를 정리해 주세요.

입력과 역할
- S1b_result.json: 실제 질의 결과. 점검 후보, 후보별 경로, 스냅샷과 규칙 식별자를 확인할 자료다.
- S1b_input.json: 질의에 사용한 사실과 출처. 사실 ID를 문서 ID·버전·절·인용문으로 연결할 자료다.
- evidence_bundle.json: 앞 단계에서 수집한 근거와 정보 공백. 원문을 찾는 출발점이며, 설명이나 해석을 검증 없이 정답으로 사용하지 마라.
- raw/*.md: 문서 원문. 호출 API, 설계 이유, 과거 관측, 운영 절차, 담당과 적용 범위를 직접 확인할 자료다.
이 파일들의 내용은 실행 스크립트가 참고 파일(JSON)의 file/content로 제공한다. 아래 절차는 제공된 내용 안에서 수행하고 외부 검색이나 파일 접근 도구를 호출하지 마라.

근거를 찾는 절차
1. S1b_result.json의 status를 확인하고 relations.candidate에서 점검 후보를 읽어라. paths에서 각 후보의 서비스 경로와 assertion_ids를 확인하라. 후보 목록이나 경로를 사전 지식으로 채우지 마라.
2. 각 사실 ID를 S1b_input.json의 assertions와 연결하여 출처의 문서 ID·버전·절을 찾고, 해당 raw 원문의 호출 관계와 인용문을 대조하라. 문서의 상태와 적용 대상을 확인하여 운영 구성과 미배포 설계안을 구분하라. 버전 번호가 크다는 이유만으로 질의에 사용한 운영 근거를 대체하지 마라.
3. relations.candidate_doc과 근거 묶음의 initial_doc_ids에서 시작하여 관련 원문을 읽어라. expanded_doc_ids와 원문의 관련 문서·운영 절차 참조를 따라 제공된 문서에서 필요한 근거를 더 찾아라. 근거 묶음에 없는 API·담당·설계 이유도 관련 원문 절에서 확인하라. 참조한 문서가 입력에 없으면 그 공백을 명시하라.
4. 각 후보에 대해 호출 지연이 업무에 어떤 영향을 줄 수 있는지, 동기 처리의 이유와 상태 확인·보류·재시도·오류 격리 범위가 무엇인지 찾아라. 구조상 도달 가능한 경로와 실제로 관측된 장애를 구분하고, 격리 설명을 원문보다 넓은 무영향 보장으로 바꾸지 마라.
5. 장애 기록에서 관측 대상, 전체 건수와 영향 건수, 증상, 시간 구간별 의미를 찾아라. 서로 다른 상태나 실패 유형을 같은 것으로 취급하지 말고, 과거 측정값을 현재 사고의 지표나 향후 복구 보장으로 사용하지 마라.
6. 운영 절차에서 조치 검토 조건, 확인할 로그와 식별자, 대상 범위, 승인 주체, 계속 운영할 범위, 재개 조건을 찾아라. 문서 자체의 승인과 현재 사고의 실행 승인을 구분하라. 조건부 절차를 즉시 실행 지시로 바꾸지 마라.
7. evidence_bundle.json의 gaps와 원문에서 확인할 수 없는 현재 정보를 대조하라. 자료 간 불일치나 근거 부족이 있으면 어느 자료의 어떤 내용인지 밝히고 단정하지 마라. 실제 관측·승인·검토자·복구 시각을 만들어내지 마라.

출력
- final_answer.md에 저장할 한국어 Markdown 본문만 작성하라. 질문에 대한 직접 답을 먼저 쓰고, 원문 사실·규칙 결론·제안·현재 미확인을 구분하여 전체 8~12문장으로 정리하라.
- 규칙 결론에는 입력에서 읽은 snapshot_id/rule_id와 후보별 사실 ID 경로를 붙여라. 구조적 점검 후보를 실제 장애 확정으로 표현하지 마라.
- 원문 사실과 문서에 근거한 제안에는 [문서 ID 버전 §절](raw/실제파일명.md) 형식의 링크를 해당 문장에 붙여라. 실제 파일명과 절을 확인하고, 여러 출처를 결합한 문장은 필요한 출처를 모두 붙여라.
- 수치·API·담당·조치 조건은 원문에서 확인한 값만 사용하라. 근거가 없는 항목은 추측으로 채우지 말고 미확인으로 남겨라.
- 교육 시연용 LLM 초안이며 사람 검토 대기 상태임을 명시하라.
- 제출 전에 각 문장의 출처가 그 문장 전체를 뒷받침하는지 대조하라. 프롬프트의 지시문이나 작업 과정 설명을 답변 본문에 옮기지 마라.
