# [장애 보고] 8/18 카드 결제 주문 완료 지연

문서 번호: INC-03 v1  
담당: 결제정산팀  
상태: 리뷰 완료  
최종 수정: 2026-08-21  
적용 대상: 직영몰 운영 환경

## 1. 장애 개요

2026년 8월 18일 09:42부터 10:07까지 원장 저장이 지연되면서 일부 카드 결제 주문이 ‘결제 확인 중’에 머물렀다. 해당 시간대 카드 결제 주문 4,900건 중 186건의 주문 확정이 지연됐다. 주문 번호 기준으로 집계했으며 화면의 반복 조회는 제외했다.

지연 건에는 PG 승인이 완료됐으나 원장 기록이 늦어진 주문도 포함돼 있었다. 고객센터에는 재결제를 안내하지 말고 기존 주문의 처리 상태를 확인하도록 공유했다. 월말 후불 정산은 이번 장애의 영향 범위에 포함되지 않았다.

## 2. 대응 내역

09:49 결제정산팀 당직자와 장애 대응 책임자가 대상 가맹점 목록을 확인한 뒤 해당 가맹점의 결제 대사 작업을 일시 중지했다. 원장 조회와 재처리가 계속 쌓이는 것을 막기 위한 조치였으며, PG 승인 API는 계속 운영했다.

이후 결제 ID별 PG 승인 내역과 원장 기록을 대조했다. 승인 결과가 확인된 건부터 기존 결제 ID로 재처리하고, 확인되지 않은 건은 보류했다. 대사 과정에서 신규 결제 승인을 요청하지 않았다.

이번 대응 내용을 바탕으로 큐 중지·재개 절차를 OPS-04 v1에 정리했다.

## 4. 원인과 후속 조치

결산 사전 집계 배치가 넓은 범위의 원장 데이터를 잠그면서 쓰기 요청이 대기했다. DB 연결 풀이 소진돼 대기가 늘었고, 결제 서비스의 원장 호출이 1.8초 타임아웃을 넘겼다. 확인한 로그에서는 네트워크 단절 징후가 없었다.
