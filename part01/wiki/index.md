# 시스템 위키

본 위키는 원문을 주제별로 정리한 초안이며, 정확한 내용 확인을 위해 사람이 원문 출처를 검토해야 합니다.

## 위키 목록

- [order](services/order.md): 직영몰 카드 결제 주문 접수, 재고 예약·견적 확인, 결제 승인 요청 및 주문 확정을 처리하는 order 서비스 안내 페이지입니다.
- [pay](services/pay.md): 카드 결제 승인 동기 처리, 원장 기록 요청 및 결제 확인·대사·재처리를 담당하는 pay 서비스 안내 페이지입니다.
- [INC-03](incidents/INC-03.md): 2026년 8월 18일 원장 쓰기 지연으로 인해 발생한 카드 결제 주문 완료 지연 장애 보고서 안내 페이지입니다.
