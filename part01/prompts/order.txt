제공한 원문 3개를 근거로 order 서비스 위키를 작성하라.
형식: 역할·소유 / 직접 API / 주문 상태 / 결정 이유 / 사고 / 미확인.
각 주장에 문서 ID, 버전, 절과 상대 파일 링크를 붙여라.
wiki/services/order.md에서 원문 링크는 ../../raw/파일명.md이다.
관련 pay 위키는 ./pay.md, 사고 위키는 ../incidents/INC-03.md로 연결하라.
승인 확인 전 주문 확정과 출고가 어떤 문제를 만드는지 원문으로 설명하라.
과거 사고와 현재 운영 상태를 구분하고 원문에 없는 현재 정보는 미확인으로 남겨라.
pay 위키는 연결을 위한 참고이며 사실은 원문과 대조하라.
원문이나 다른 파일은 변경하지 말고 order.md에 저장할 Markdown 본문만 반환하라.
