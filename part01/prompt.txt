제공한 업무 원문으로 pay 서비스 위키 초안을 작성하라.
형식: 역할·소유 / 직접 API / 오류 상태 / 사고 / 미확인.
각 주장에 문서 ID, 버전, 절과 상대 파일 링크를 붙여라.
승인 실패와 원장 응답 지연을 구분하라.
과거 조치의 대상·승인 조건을 유지하라.
현재 당직자와 향후 복구 시간을 추측하지 말라.
원문은 보존하고 wiki/services/pay.md만 제안하라.
원문 링크는 ../../raw/파일명.md, 관련 order 위키는 ./order.md, 사고 위키는 ../incidents/INC-03.md로 연결하라.
OPS-04의 내용은 현재 입력에 없으므로 후속 확인 대상으로만 기록하라.
파일 저장은 실행 스크립트가 담당한다. Markdown 본문만 반환하라.
