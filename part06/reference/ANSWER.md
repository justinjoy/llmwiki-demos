# 6교시 정답 해설

한빛MRO 합성 문서 기반 예시입니다. 실제 검토자·일자는 수강생이 기록합니다. 문구가 달라도 근거·범위·상태가 같으면 됩니다.

## PPT 11: 실습 A 확인: 근거 묶음

문서의 역할에 따라 답의 종류가 달라집니다.

| 문서 | 확인 내용 | 근거 | 해석 범위 |

## PPT 13: 실습 B 확인: 조건부 답변

과거 관측과 현재 조치 판단을 구분합니다.

### 적합한 답변

OPS-04 조건을 먼저 확인합니다.
승인된 영향 가맹점 대사 큐만 제어합니다.
25분은 과거 신규 요청 영향 구간입니다.

### 추가 확인

현재 지연 지속 시간·영향 merchant_id
PG 승인과 원장의 불일치 여부
장애 대응 책임자·담당 당직 승인 기록

보류 건의 대사 완료는 42분이며 미래 복구 예상은 미확인입니다.

## PPT 16: 확인 문제 해설

승인의 대상과 복구 완료 기준을 구분합니다.

### 질문 1의 답

절차 승인과 건별 실행 승인은 다릅니다.
현재 조건과 영향 범위를 확인하고
지정된 승인 기록을 남겨야 합니다.

### 질문 2의 답

INC-03에서는 대사 완료가 42분입니다.
신규 요청 정상화와 잔여 처리 완료는
별도 시각으로 기록합니다.
