제공된 업무 원문으로 2교시 온톨로지의 타입 사전을 작성하라.
업무 질문은 ledger 호출 경로상 점검 대상, pay의 운영 책임, 대사 조치의 현재 적용 여부이다.
출력은 types.csv에 저장할 CSV 본문만 반환하라. 설명 문단이나 코드 블록을 붙이지 말라.
헤더는 정확히 다음과 같다: 타입,정의,식별자 예,속성,근거
Service, API, Team, Document, Incident, Policy, DataStore의 7개 타입을 정의하라.
타입을 정의하는 설계 제안과 실제 개체가 존재한다는 원문 사실을 구분하라.
Service·API·Team·Document·Incident는 제공된 원문에서 실제 예와 문서 버전·절을 찾아라.
API 식별자는 소유 서비스·HTTP 메서드·경로를 포함하라. 호출 타임아웃은 호출 구간별 속성으로 구분하라.
Policy는 ADR-07의 OPS-04 참조를 후보로 기록하되 아직 읽지 않은 OPS-04의 상세 조건을 만들지 말라.
DataStore 타입은 모델링 후보로 정의하라. ledger-db라는 개체의 존재·타입·소유 서비스는 입력 원문에 명시되지 않았다면 확인 보류로 적어라.
payment와 pay의 동일성, 현재 당직자 이름, 미제공 정책 조건을 추측하지 말라.
식별자 예에 svc:나 api: 접두어를 쓰면 수업용 식별 규칙으로 정한 예임을 정의에 표시하라.
속성 등 필드에 쉼표나 줄바꿈이 있으면 CSV 규칙에 따라 큰따옴표로 감싸라.
